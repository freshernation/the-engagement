# Your first slice

Your code for week 2 lives here. Structure it however your earlier courses taught you.

Copy in what you need on Monday morning: your agent, your retrieval code, your model
layer, your service. Keep a `README.md` in this folder saying how to run it, which the
handover on Thursday will point at.

There are no tests for this folder. The tests for this week are the customer's cases in
`day-1/evals.jsonl`, and the grader is the customer.
